# Formation et transfert de compétences

## Programme (≈ 5 jours)
| Module | Public | Durée | Contenu |
|---|---|---|---|
| 1. Métier VAS & back-office | VAS Manager, Support, Finance | 1 j | services, mots-clés, consentement/STOP, tarifs 4-yeux, rapprochement, exports |
| 2. Portail & API partenaires | Support, intégrateurs partenaires | 0,5 j | clés/scopes, OpenAPI, webhooks HMAC, idempotence |
| 3. Exploitation NOC | NOC / Ops | 1 j | Grafana/Loki, runbooks (lien coupé, throttling, backlog, DLQ), simulateur SMPP |
| 4. Administration technique | Admin système | 1,5 j | déploiement compose/HA, Jasmin (`jcli`), secrets, sauvegarde/restauration, bascule |
| 5. Code & évolution | Développeurs du client | 1 j | architecture, tests, CI, ajout d'un opérateur/service/canal, migration Flyway |

## Livrables transférés
Dépôt Git complet (code, migrations, infra, scripts, documentation), `.env.example`, comptes et secrets de production générés par le client, matrice de licences, supports de formation.
